# Rand-Q

Генератор случайных поисковых запросов (Random Query). Веб-приложение, которое помогает найти неожиданные и нестандартные темы для поиска, вдохновения или развлечения.

## Описание проекта

Rand-Q — это легкий и быстрый инструмент, который генерирует уникальные поисковые запросы при каждом взаимодействии. Проект создан как демонстрация работы с DOM-манипуляциями и базовой логикой на стороне клиента без использования тяжелых фреймворков.

---

## Стек технологий

- **HTML5** — семантическая разметка страницы
- **JavaScript (ES6+)** — логика генерации случайных запросов и взаимодействие с пользователем
- **Tailwind** — стилизация интерфейса 

---

## Запуск локально

Проект является полностью статическим и не требует установки зависимостей (Node.js, Python и т.д.).

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Kievsky332/Rand-Q.git
   ```
2. Перейдите в проект
    ```bash
   cd Rand-Q
   ```
3. Откройте файл index.html двойным кликом в любом современном браузере.
